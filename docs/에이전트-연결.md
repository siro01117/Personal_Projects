# 에이전트 연결(원격 MCP) · 도움말 — 설계서 v1 (2026-10-04)

회원이 **자기 PC 의 Claude** 에서 EZ.WORK 를 쓰게 한다. 사이트에서 토큰을 하나 발급받아 명령 한 줄을 붙여 넣으면 끝. 그리고 모듈마다 아래쪽에 떠 있는 **도움말**에서 "이 모듈에서 에이전트에게 뭘 시킬 수 있나" 를 본다.
`docs/보고서-서랍.md` 8장(원격 MCP — 나중)의 "개인 토큰" 을 지금 만든다. OAuth(주소만 넣기)는 여전히 나중.

## 0. 정해진 것 (2026-10-04)

- 다른 회원도 각자 PC 에서 쓸 수 있게 한다. 방식은 **개인 토큰**
- 쓰는 사람이 하는 일: 설정에서 **토큰 만들기 → 화면에 나온 명령 한 줄을 복사 → 터미널에 붙여 넣기**. 그 뒤로는 그 PC 의 Claude Code 가 EZ.WORK 도구를 쓴다
- AI 비용은 각자의 Claude 구독. EZ.WORK 서버는 AI 를 부르지 않는다
- 모듈마다 아래쪽 **플로팅 도움말** 단추 → 팝업
- 한결의 로컬 MCP(`.mcp.json`, stdio, service_role)는 그대로 둔다

## 1. 데이터 — `ez_tokens`

| 칸 | 규칙 |
|---|---|
| `id` `owner`(default auth.uid()) `created_at` | RLS `owner = auth.uid()` |
| `name` | 1~30자. "집 노트북" 처럼 어디서 쓰는지 |
| `hash` | 토큰의 sha256(hex). **토큰 원문은 저장하지 않는다** |
| `tail` | 토큰 끝 4자(목록에서 알아보게) |
| `scope` | `rw`(기본) · `ro`(읽기만 — 쓰는 도구를 부르면 거절) |
| `last_used_at` `revoked_at` | 폐기는 `revoked_at` 을 적는다(행은 남긴다) |

- 토큰 모양: `ezt_` + 무작위 40자(base62). 만들 때 **한 번만** 보여 준다
- 사람당 살아 있는 토큰 10개까지
- 만들기는 DB 함수 `ez_token_new(name, scope)`(무작위를 DB 가 만들고 원문을 돌려준 뒤 해시만 저장) · 폐기는 `revoked_at` update(주인만). 서버가 쓰는 확인 함수 `ez_token_check(p_token)` → `{owner, scope}` 또는 없음(security definer, **service_role 에만** 실행 권한 — anon · authenticated 는 못 부른다). 폐기됐거나, 주인이 회원인데 `active = false` 이거나, 주인이 관리자도 회원도 아니면 없음. 통과하면 `last_used_at` 갱신(분 단위로만 — 요청마다 쓰지 않게)
- **DELETE · DROP 문 없이**(DB 도구 제약)

## 2. 서버 — `/api/mcp`

- Next 라우트(Node 런타임, `preferredRegion = "sin1"`), **Streamable HTTP, 상태 없음**(요청마다 독립 — 세션 저장 없음). SDK 는 지금 쓰는 `@modelcontextprotocol/sdk`
- 인증: `Authorization: Bearer ezt_…`. 없거나 틀리면 401(JSON-RPC 오류 본문과 함께). 토큰 → 주인 → **그 사람 것만**
- 도구: 로컬과 **같은 도구**(`mcp/tools.ts` 의 `registerTools` 를 그대로 쓴다 — 규칙은 한 곳). `scope = ro` 면 쓰는 도구(`*_save` · `*_delete` · `*_update` · `*_mkdir` · `*_create` · `*_edit` · `*_sync`)를 등록하지 않는다
- **남의 데이터가 절대 안 보이게** — 원칙: 토큰 주인의 권한으로 DB 에 들어가 RLS 가 막게 한다
  - 구현 에이전트가 먼저 조사한다: 지금 스토어(`mcp/*store-supabase.ts`)는 service_role + 코드의 `owner` 조건이다. (가) 그 사람의 세션으로 만든 클라이언트(RLS 적용)로 스토어를 돌릴 수 있는지 — DB 함수는 `ez_actor` 가 `auth.uid()` 를 쓰므로 되지만, 직접 테이블 쓰기 중 authenticated 에 권한이 없는 칸(예: 사진 업로드 · `agent_updated_at`)이 있는지 본다. 되면 (가)
  - (가)가 안 되는 도구는 (나) service_role + `owner` 조건으로 두되, **도구마다 "다른 사람 id 로는 아무것도 못 읽고 못 고친다" 는 교차 시험**을 넣는다. 어느 도구가 (나)인지 보고에 적는다
  - 어느 쪽이든 PGlite 로 두 사용자를 만들어 **모든 도구를 남의 id 대상으로 한 번씩 부르는 시험**이 통과해야 한다
- 사진: 원격에서는 `local_path`(그 PC 의 파일 경로)를 서버가 읽을 수 없다 → 원격 MCP 에서 사진 블록은 1차에 **지원하지 않는다**(넣으려 하면 "원격 연결에서는 사진을 넣을 수 없습니다" 로 거절). 로컬 MCP 는 그대로
- 한도: 토큰당 1분 120회(넘으면 429). 요청 본문 1MB
- 서버 키: 이미 있는 `EZ_SUPABASE_SERVICE_ROLE_KEY`(Vercel, 서버 전용)

## 3. 화면 — 설정 "에이전트 연결"

- 들어가는 곳: 사이드바 맨 아래 톱니(없으면 추가 모듈 · 회원 줄 근처) → `/settings/agent`. 회원 · 관리자 모두
- 목록: 토큰마다 이름 · 끝 4자(`…a1b2`) · 범위(읽고 쓰기 / 읽기만) · 마지막 사용(상대 시간) · 폐기. 폐기는 확인 한 번
- **토큰 만들기**: 이름 · 범위 → 만들면 **한 번만** 보이는 상자:
  - 붙여 넣을 명령 한 줄(복사 단추): `claude mcp add --transport http ezwork https://ra-kan.cloud/api/mcp --header "Authorization: Bearer ezt_…"`
  - 그 아래 작은 글자 두 줄: "터미널에 붙여 넣으세요" · "이 창을 닫으면 다시 볼 수 없습니다"(이건 없으면 막히는 문구라 넣는다)
  - Claude Code 가 아닌 클라이언트를 위해 주소와 토큰을 따로 복사하는 단추 둘
- 관리자 화면(`/admin`) 회원 시트에 "토큰 n개 · 전부 폐기"(회원이 PC 를 잃어버렸을 때). 회원을 끄면(`active=false`) 토큰은 폐기하지 않아도 확인 함수가 막는다

## 4. 도움말 — 모듈마다 아래쪽 플로팅

- 모듈 화면(서랍 · 보고서 · 일정 · 플래너 · 작업대 · 모임 · 회원 · 설정) **오른쪽 아래에 작은 둥근 `?` 단추**(떠 있음, 다른 플로팅 — 고치기 도구 줄 · 알림 — 과 겹치지 않게 자리 조정. 폰은 safe-area 위)
- 누르면 팝업(종이색 라운드 사각형, 폭 360, 폰은 아래 시트). 바깥 누르기 · Esc 로 닫힘. 내용은 **그 모듈 것만**, 세 묶음:
  1. **이 화면** — 조작 4~6줄(예: 플래너 "N = 새 할 일 · 우클릭 = 메뉴 · 역할 칩으로 거르기 · 끌어서 순서")
  2. **에이전트에게** — 그 모듈의 도구로 할 수 있는 말 예시 3~5개. 누르면 복사(예: "내일까지 할 일 중 대학 것만 알려 줘" · "이 보고서 3번 블록 표에 행 하나 추가해 줘"). 작은 글자로 쓰는 도구 이름
  3. **연결** — 토큰이 하나도 없으면 "에이전트 연결" 단추(→ `/settings/agent`), 있으면 "연결됨 · 마지막 사용 n분 전" 한 줄
- 내용은 `lib/help.ts` 한 곳(모듈 키 → 조작 줄 · 예시 문장 · 도구 이름). 도구 이름은 `mcp/tools.ts` 의 실제 이름과 맞는지 시험으로 확인한다
- 미니멀 규칙의 예외: 도움말은 **눌러야 보이는 곳**이라 설명 문구를 쓴다. 화면 본체에는 여전히 설명을 넣지 않는다
- 공개 페이지(`/s/…` · `/m/…`)와 로그인 화면에는 없다

## 5. 시험

- DB: 토큰 원문이 어디에도 저장되지 않음 · 확인 함수는 service_role 만 · 폐기 · 꺼진 회원 · 10개 상한 · `ro`
- 서버: 토큰 없음/틀림 401 · `ro` 는 쓰는 도구가 목록에 없음 · 한도 429 · **두 사용자 교차 시험(모든 도구)**
- 화면: 만들기 → 한 번 보이는 상자 · 폐기 · 도움말 팝업(모듈별 내용, 도구 이름 일치)

## 6. 뺀 것 · 나중

OAuth(주소만 넣기 — claude.ai 커넥터 · 폰) · 원격에서 사진 넣기 · 토큰 만료일 · 도구별 세부 권한 · 사용 통계
