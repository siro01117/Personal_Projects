# 플래너 — 설계서 v2

> 2026-10-01. EZ.WORK 세 번째 모듈. 일정과 같이 만든다.
> 원칙은 보고서 서랍·일정과 같다. 규칙은 한 곳(`lib`·DB), 미니멀 1차, 에이전트는 MCP 로.

## 0. 정해진 것

- 플래너 = **시간이 안 정해진 할 일**. 시간이 정해지면 일정으로 간다
- 주로 **개인 할 일**을 쓴다. 일하면서 생기는 할 일은 나중에 프로젝트 모듈에서, 약속은 모임 모듈에서 넘어온다
- 그래서 일정에 직접 넣는 일은 드물다. 일정은 **플래너·프로젝트·모임·바깥 일정이 모이는 곳**이다
- 없는 것: 우선순위, 하위 할 일 여러 단, 태그·목록 나누기, 자동 배치. 반복 · 지점 · 체크 항목 · 지남 묶음은 7장(v2)에서 더했다
- 누르면 보기만, 고치기는 '수정' 을 한 번 더 (일정과 같은 규칙). 단 **끝냄 체크는 바로** 된다

레퍼런스: **Things 3**(조용한 목록, 끝낸 것은 접힘), **Sunsama·Akiflow**(할 일을 캘린더로 끌어 시간 붙이기).

## 1. 흐름

```
프로젝트 ─┐                    ┌─ 모임
          ▼                    ▼
       플래너(시간 없음) ──시간 정하기──▶ 일정(시간 있음) ◀── 바깥 일정(sync)
```

- 할 일 하나에 일정은 **최대 하나**. 시간을 정하면 일정이 생기고 할 일과 이어진다
- 이어진 일정을 지우면 할 일은 다시 '시간 없음' 으로 돌아온다
- 할 일을 끝내도 일정은 남는다(그 시간에 했다는 기록). 일정 블록에 끝냄 표시
- 할 일을 지우면 이어진 일정은 남고 연결만 끊긴다

## 3. 화면

**플래너 페이지** `/planner`
- 맨 위 한 줄 입력: 쓰고 Enter 면 맨 위에 추가. 한글 조합 중 Enter 무시
- 목록 셋, 위에서 아래로
  1. **할 일** — 시간 없음 · 안 끝남. 손으로 끌어 순서 바꾸기(데스크톱)
  2. **시간 정함** — 이어진 일정이 있는 것. 날짜·시각 순. 오른쪽에 "10/3 금 14:00"
  3. **끝냄** — 최근 14일만, 접혀 있음. 펼치면 보임
- 줄 하나: 동그라미(끝냄 체크) · 제목 · 마감("10/5 까지", 지나면 빨강) · 걸릴 시간("1시간")
- 줄 누르기 → 보기(데스크톱 오른쪽 패널, 폰 보기 시트): 제목 · 마감 · 걸릴 시간 · 메모 · 이어진 일정 · [시간 정하기] [수정] [없애기]
- **시간 정하기** → 날짜 · 시작 시각(기본: 그날 첫 빈 시간) · 길이(기본 `est_min`). 저장하면 일정이 생긴다
- 끝냄 체크는 누르면 바로. 알림에 '되돌리기'

**일정 페이지에서**
- 데스크톱 오른쪽 패널: 아무 블록도 안 고른 때는 **할 일(시간 없음) 목록**. 끌어서 격자에 놓으면 그 자리(15분 단위)에 일정이 생긴다
- 할 일에서 온 일정 블록: 제목 앞에 작은 동그라미. 상세에 '할 일에서 옴' + 끝냄 체크
- 폰: 할 일에서 시간 정하기는 플래너 쪽에서만

## 4. MCP 도구 (2개)

| 도구 | 하는 일 |
|---|---|
| `todo_list(status?, query?)` | `open`(기본: 안 끝남) / `done` / `all`. 각 줄에 이어진 일정(날짜·시각)까지 |

## 7. v2 — 실사용 조사로 더한 것 (2026-10-01)

근거: 서랍 보고서 "플래너에 필요한 것 — 할 일 종류 · 엣지케이스 · 벤치마킹". 라칸에서 실제로 쓰던 할 일 12개와 제품 12종 비교.

### 7-1. 지남 묶음

- 목록 맨 위에 **지남**. 들어가는 것(안 끝낸 것 중)
  - 이어진 일정이 끝났다(날짜가 지났거나, 오늘이고 끝 시각이 지남)
  - 마감이 지났다
- 줄 오른쪽에 무엇이 지났는지: "10/1 목 15:30 지남" 또는 "9/27 까지"(빨강)
- 누르면 보기. 버튼은 상황에 맞게
  - 지난 일정: [끝냄] [다시 정하기] [시간 없음으로] — '시간 없음으로' 는 이어진 일정을 지우고 할 일 목록으로
  - 지난 마감: [끝냄] [마감 바꾸기] [마감 지우기]
- **자동으로 다음 날로 넘기지 않는다.** 시각이 있는 것은 사람이 다시 잡는다(Marvin 방식). 넘기기만 하면 목록이 썩는다
- ~~묶음이 비면 제목째 숨긴다~~ → **자리를 고정한다**(2026-10-04, 7-14). 비어도 카드와 제목은 그 자리에 있고 안에 "없음" 한 줄

### 7-2. 반복 할 일 (규칙이 할 일을 만든다)

반복은 할 일 한 줄이 되살아나는 게 아니라, **규칙**이 때가 되면 새 할 일을 만든다. 끝낸 것은 기록으로 남는다.

| 종류 | 예 | 언제 생기나 |
|---|---|---|
| `cycle` 주기 | 주간 숙제, 주간 정리 | 매일 / 매주 정한 요일에. 시간은 안 정한다 — 그 주 안에 아무 때나 |
| `event` 일정에 딸림 | 수업 끝나면 "상법 내용 정리" | 그 반복 일정의 회차가 끝날 때마다 |

- 규칙의 칸: 제목 · 메모 · 걸릴 시간 · 지점 · 체크 항목 · **마감까지 며칠**(`due_after`, 없으면 마감 없음. 주간 숙제가 월요일에 생기고 `6` 이면 일요일까지)
- **밀리면 한 건만**: 새 회차를 만들 때 그 규칙의 안 끝낸 지난 회차는 지운다(쌓지 않는다). Todoist · OmniFocus · Sunsama 와 같다. 이어 둔 일정이 있었으면 일정은 남고 연결만 끊긴다
- 오래 안 열었어도 **가장 최근 회차 하나만** 만든다(밀린 회차를 줄줄이 만들지 않는다)
- 만드는 때: 서버가 없어서 **열 때** 만든다. 플래너·일정 화면을 열 때와 `todo_list` 를 부를 때 DB 함수 `ez_tasks_roll` 을 부른다. 같은 회차는 한 번만(규칙 + 회차 날짜 유일)
- 일정에 딸린 규칙: 회차가 건너뜀(skip)이면 안 만든다. 일정을 지우면 규칙도 멈춘다
- 반복 멈추기: 규칙을 멈춘다. 이미 생긴 할 일은 남는다
- 화면
  - 할 일 수정 칸에 **반복**: 안 함 / 매일 / 매주(요일) + 마감까지 며칠. 저장하면 규칙이 생기고 지금 할 일이 첫 회차가 된다
  - 반복에서 생긴 할 일은 줄에 작은 반복 표시. 제목·걸릴 시간·지점을 고치면 '이번만 / 앞으로도'
  - 일정 수정 칸(반복 일정일 때) '더보기' 아래 **끝나면 할 일**: 제목(비우면 없음) + 마감까지 며칠
- 끝낸 날 기준 반복(이발)은 아직 없다

### 7-3. 일정에 딸린 마감

- 마감을 날짜 대신 **일정으로** 고를 수 있다("송현이 누나 결혼식 전까지"). 고른 회차의 날짜가 마감이 된다
- 반복 아닌 일정의 날짜가 바뀌면 마감도 따라간다. 일정을 지우면 연결만 끊기고 날짜는 남는다
- 줄에는 평소처럼 "10/11 까지", 보기에는 일정 제목도

### 7-4. 지점

- 할 일에 지점 하나(없어도 됨). 줄 제목 앞에 지점 심볼
- 시간을 정하면 그 지점이 일정의 지점이 된다 → 동선 계산에 들어간다
- 일정 화면의 할 일 목록에도 심볼이 보인다

### 7-5. 일정으로 보내기

- 보기의 더보기 메뉴에 **일정으로**: "수, 일 스탠드업" 처럼 사실은 일정인 것. 일정 입력 칸이 제목·메모·지점을 채운 채 열리고, 저장하면 일정이 생기고 할 일은 지운다(되돌리기 가능)

### 7-6. 체크 항목 (한 단)

- 할 일 안에 체크 항목 최대 50개(0016 에서 20 → 50, 7-13), 각 1~100자. 한 단뿐 — 여러 단은 프로젝트 모듈의 몫
- 보기에서 체크는 바로 된다. 줄에는 "1/2". 다 체크해도 할 일이 자동으로 끝나지는 않는다
- 수정 칸에서는 한 줄에 하나씩 적는다

### 7-7. 데이터 (0007)

`ez_tasks` 에 더하는 열

| 열 | 뜻 |
|---|---|
| `place_id` | 지점 (같은 주인) |
| `due_event_id` | 마감을 딸려 둔 일정. `due` 는 그 회차 날짜의 사본 |
| `checklist` jsonb | `[{t, done}]` 0~50개 (0016) |
| `rule_id`, `rule_date` | 어느 규칙의 어느 회차에서 생겼나. 같은 (규칙, 회차)는 하나 |

`ez_task_rules` 반복 규칙

| 열 | 뜻 |
|---|---|
| `id`, `owner` | |
| `kind` | `cycle` / `event` |
| `title`, `note`, `est_min`, `place_id`, `checklist` | 만들 할 일의 모양 (checklist 는 글자 배열) |
| `repeat`, `start` | cycle 만. 일정과 같은 반복 모양(매일 / 매주 요일). `start` 부터 |
| `event_id` | event 만. 반복 일정 |
| `due_after` | 생긴 날부터 마감까지 며칠 (0~60). null 이면 마감 없음 |
| `last_made` | 마지막으로 만든 회차 날짜 |
| `version`, `deleted_at` | 멈추면 `deleted_at` |

함수 `ez_tasks_roll(p_today date, p_now_min int, p_as uuid default null)` → 만든 개수. 규칙마다 `last_made` 보다 뒤이고 오늘 이하인 가장 최근 회차 하나를 찾아 만든다. event 규칙은 회차의 끝 시각이 지나야 한다.

### 7-8. MCP

도구 수는 그대로 2개. 칸만 는다.

- `todo_list`: 부를 때 먼저 roll. 각 줄에 `place` · `checklist` · `late`(무엇이 지났나) · `repeat`(규칙에서 왔으면 요약). `status: "rules"` 면 반복 규칙 목록
- `todo_save`: `place`(지점 이름) · `checklist`(글자 배열 또는 `[{t, done}]`) · `due_event`(일정 id + 회차 날짜) · `repeat`(`{freq, days}` 또는 `{after_event: 일정 id}`) + `due_after`. `rule_id` + `stop: true` 로 반복 멈추기

### 7-10. 배치 · 시간 비우기 (2026-10-01 밤)

- **두 열**: 넓으면 왼쪽에 지남 · 할 일(지금 할 것), 오른쪽에 시간 정함 · 끝냄(정해 둔 것과 끝낸 것). 목록 폭 720px 미만이나 폰은 한 열로 위에서 아래로. 오른쪽에 둘 것이 없으면 한 열(최대 760px)
- **묶음 구분**: 회색 바탕(`--canvas`) 위 흰 종이 카드(`--paper`) — 보고서 화면과 같은 결. 묶음 머리에 작은 점(지남 빨강 · 할 일 키위 · 나머지 빈 점) + 이름 + 개수. 폰에서는 카드가 화면 폭을 다 쓰고 사이에 얇은 띠
- 줄이 좁아질 때 덜어내는 기준은 화면이 아니라 **카드 폭**
- **시간 정한 것도 되돌릴 수 있다**: 아직 안 지난 '시간 정함' 할 일의 보기에 [다시 정하기] [시간 없음으로]. 다시 정하기는 정해 둔 날짜·시각에서 시작한다. 반복 일정에 이어진 것은 일정 쪽에서

### 7-11. 역할 — 누구로서 하는 일인가 (2026-10-01 밤)

지점이 "어디서" 라면 역할은 "누구로서". 대학(학생) · 강사 · 개인처럼 사회적 역할로 할 일을 가른다.

- 할 일마다 **역할 하나**(없어도 됨). 여러 개 붙이는 태그가 아니다
- 역할 목록은 사람마다 있고 **더하고 고칠 수 있다**. 처음에는 대학 · 강사 · 개인 셋. 최대 12개, 이름 1~20자, 겹치면 안 됨
- **지점에서 자동으로**: 역할에는 '어느 지점 역할에서 오나'(`from_place`: school / work / home / 없음)가 있다. 기본값은 대학 ← school, 강사 ← work, 개인 ← home. 할 일에 지점을 고르면 그 지점 역할에 맞는 역할이 들어간다(손으로 바꿀 수 있고, 손으로 고른 뒤에는 지점을 바꿔도 안 덮는다)
- 반복 규칙도 역할을 가진다. 규칙이 만드는 할 일은 그 역할로 생긴다. 일정에 딸린 규칙은 일정의 지점에서 기본 역할을 얻는다
- 일정에는 아직 역할이 없다(필요해지면 더한다)
- 화면
  - 줄에 작은 회색 글자로 역할 이름(색 없음 — 색은 지점이 쓴다). 좁아지면 걸릴 시간 다음으로 먼저 빠진다. 역할별로 정렬했을 때는 줄에서 빼고 구분선에 적는다
  - 역할로 **거르지 않는다** — 정렬로 본다(7-12). 역할 편집 버튼은 정렬 줄 끝에
  - 수정 칸에 역할 칩(없음 포함). 보기에는 한 줄
  - 역할 편집: 이름 바꾸기 · 더하기 · 지우기(지우면 그 역할의 할 일은 역할 없음이 된다) · 순서
- 데이터 (0008)
  - `ez_roles`: `id`, `owner`, `name`, `from_place`(home/work/school/null — 살아 있는 것 중 값마다 하나), `sort`, `version`, `deleted_at`
  - `ez_tasks.role_id`, `ez_task_rules.role_id` — 같은 주인의 역할. 역할 행이 지워지면 null
  - `ez_roles_seed(p_as uuid default null)` → 만든 개수. 그 주인에게 역할 행이 **하나도 없을 때만**(지운 것 포함) 기본 셋을 넣는다. 화면을 열 때와 MCP 가 부른다
  - `ez_tasks_roll` 이 새 할 일을 만들 때 규칙의 `role_id` 를 옮긴다
- MCP (도구 수 그대로): `todo_list` 에 `role`(이름) 필터와 각 줄의 `role`, 결과에 `roles` 목록. `todo_save` 에 `role`(이름, null 이면 비움, 없는 이름이면 가까운 이름 제안). 지점을 주고 역할을 안 주면 지점에서 채운다

### 7-12. 정렬 (2026-10-02, 역할 필터를 대체)

걸러서 일부만 보는 대신, 전부 보되 **순서와 묶음**을 바꾼다.

- 위쪽 줄 아래 정렬 줄: **직접 · 역할 · 장소 · 소요시간** + 오름/내림 전환 버튼 + 끝에 역할 편집. 고른 정렬은 이 기기에 기억(`ezwork.planner.sort`)
- 네 묶음(지남 · 할 일 · 시간 정함 · 끝냄) 안에서 각각 적용한다. 묶음 자체는 그대로
- **직접**: 손으로 정한 순서(기본). 끌어서 순서 바꾸기는 이 정렬에서만 된다. 오름/내림 버튼은 숨긴다. 시간 정함은 일정 시각 순, 끝냄은 끝낸 시각 최근순(지금까지와 같다)
- **역할**: 역할 목록 순서대로 묶는다. 역할 없는 것은 늘 맨 뒤. 묶음 안은 직접 순서. 내림이면 역할 순서만 뒤집는다
- **장소**: 지점 순서(설정의 순서)대로 묶는다. 지점 없는 것은 늘 맨 뒤. 묶음 안은 직접 순서
- **소요시간**: 걸릴 시간(`est_min`) 순. 오름 = 짧은 것부터. 안 적은 것은 늘 맨 뒤(그 안은 직접 순서), 같은 값이면 직접 순서. 마감·일정 시각은 보지 않는다 (2026-10-02 정정 — 처음엔 마감·일정 시각으로 잘못 만들었다)
- **경계 구분**: 역할 · 장소 정렬에서는 값이 바뀌는 자리에 조금 띄우고 가는 선을 넣는다. 선 왼쪽에 작은 회색 글자로 그 값(역할 이름 / 지점 색 점 + 이름 / '없음'). 묶음이 하나뿐이어도 적는다. 소요시간 정렬에는 구분선이 없다
- 맨 위 입력으로 추가한 할 일은 역할·지점 없이 들어간다(직접 순서의 맨 위)

### 7-13. 작업대 — 지금 하는 일을 쪼개며 한다 (2026-10-04)

> "상법 내용 정리" 라고 적어 두고, 막상 컴퓨터에 앉으면 **어떻게 정리할지 계획하고 그대로 해 나가고 싶다.** 할 일 목록은 "무엇을" 이고, 작업대는 "지금 이걸 어떻게" 다.

- **작업대에는 한 번에 할 일 하나**만 올라간다. 올리면 플래너 맨 위에 작업대 카드가 생긴다(다른 묶음보다 위, 폰도 같다). 비어 있으면 카드 자체가 없다
- **올리기**: 할 일을 보기 → '작업대에' 단추. 다른 것이 올라가 있으면 바꿔 올린다(내려간 것은 단계 · 메모가 그대로 남는다)
- **작업대 카드 안**
  - 위: 제목 · 역할 · 지점 점 · 걸릴 시간 · 올린 지 얼마나 됐는지(분, 올릴 때 `bench_at` 을 적고 화면이 센다 — 타이머가 아니라 "앉은 지 40분")
  - **단계**: 그 할 일의 체크 항목(7-6)이 그대로 단계다. 빈 줄에 적고 **Enter 면 저장 + 다음 빈 줄**, Shift+Enter 줄바꿈 없음(한 줄 칸), 한글 조합 중 Enter 무시. 체크는 바로. 끌어서 순서 바꾸기(플래너 직접 정렬과 같은 끌기). 단계마다 오른쪽에 '떼어내기' — 그 줄이 **새 할 일**이 된다(제목 = 그 줄, 역할 · 지점 · 마감은 지금 할 일에서 물려받음, 단계에서는 빠진다)
  - **메모**: 그 할 일의 메모(`note`)가 그대로. 여러 줄, 벗어나면 저장. 계획 · 중간 결과 · 다음에 할 것을 적는 자리
  - **새 할 일**: 맨 아래 한 줄 — 하다가 떠오른 다른 일을 바로 할 일 목록에(작업대 할 일과 무관한 보통 할 일. 역할 · 지점은 비움)
  - 아래 단추: **끝냄**(할 일이 끝나고 작업대가 빈다) · **내려놓기**(목록으로, 단계 · 메모 유지)
- 체크 항목 상한을 20 → **50** 으로 올린다(단계로 쓰면 20 은 모자란다). 각 1~100자는 그대로
- 데이터(`0016`): `ez_tasks.bench_at timestamptz`(null 이면 안 올라감). 사람당 하나 — 올릴 때 다른 것의 `bench_at` 을 비운다(DB 함수 `ez_task_bench(id, on)` 한 번에). 끝내거나 지우면 비운다
- MCP: `todo_save` 에 `bench: true | false`, `todo_list` 는 작업대 할 일을 맨 위에 `bench: true` 로. 에이전트가 단계를 넣는 길은 지금 `checklist` 그대로
- 데스크톱 두 열에서는 작업대 카드가 **두 열에 걸쳐** 맨 위. 폰은 맨 위 한 장
- 뺀 것: 타이머 · 뽀모도로 · 단계마다 걸릴 시간 · 여러 개 올리기 · 작업 기록(언제 얼마나 했는지 남기기)
- 만든 모양 (2026-10-04)
  - 함수 이름은 `ez_task_bench(id uuid, p_on boolean, p_as uuid default null)` → 고친 할 일 행. `on` 은 SQL 예약어라 `p_on`. 이미 올라가 있으면 그대로(시각 · 버전 안 바뀜), 끝낸 것을 올리면 `[EZ_VALUE]`, 없거나 지운 것은 `[EZ_NOT_FOUND]`. 사람당 하나는 부분 유일 색인(`ez_tasks_bench_one`)이 한 번 더 막는다. 트리거 `ez_tasks_bench` 는 끝냄 · 지움에 더해 끝낸 채 넣는 경우도 비운다
  - 상한 50 은 반복 규칙의 체크 항목 글자(`ez_check_texts_ok`)에도 같이 — 상수(`CHECKLIST_MAX`)를 같이 쓰고 규칙이 만드는 할 일의 단계가 되므로
  - 올린 지 1분이 안 됐으면 "방금 앉음", 60분부터 "앉은 지 1시간 5분"
  - 넓으면(목록 폭 720px 이상) 카드 안이 두 칸: 왼쪽 단계, 오른쪽 메모. 제목은 누르면 보기가 열린다(수정 · 시간 정하기는 거기서)
  - 떼어내기 단추는 마우스로 줄에 올렸을 때 보인다(터치 화면은 늘). 되돌리기는 새 할 일을 지우고 단계를 원래 자리에 넣는다
  - 끝냄을 되돌리면 작업대에도 다시 올린다
  - 보기의 '작업대에' 는 안 끝냈고 아직 안 올라간 할 일에만. 목록 줄 앞 표시는 작은 키위 막대
  - `todo_save` 의 `bench` 는 `done: true` · `delete` · 규칙만 고치기(`rule_id`) · '일정 끝나면' 규칙 만들기와 같이 못 쓴다

### 7-14. 역할 필터(여럿 고르기) · 카드 자리 고정 (2026-10-04)

- **역할 필터**가 돌아온다(7-12 에서 정렬로 대체했던 것) — 정렬과 **같이** 쓴다. 정렬 옆 '역할' 단추 → 시트에 역할마다 체크(여럿). 기본은 전부 켬. 체크를 풀면 그 역할의 할 일이 목록에서 빠진다(작업대 카드는 필터와 무관). 하나라도 끄면 단추에 키위 점. 기기에 기억(`localStorage`). 역할 없는 할 일은 '역할 없음' 줄로 같이 고른다
- 만든 모양 (2026-10-04): '역할' 단추는 정렬 줄 오른쪽 끝(역할 편집 연필 앞) — 정렬의 '역할' 칩과 떨어뜨려 둔다. 시트는 역할 편집과 같은 그릇(오른쪽 패널 · 폰 시트). 켠 것이 아니라 **끈 것**을 기억(`ezwork.planner.roles`)해서 새 역할은 처음부터 켜져 있다. 지운 역할을 가리키는 할 일은 '역할 없음' 으로 친다
- **카드 자리 고정**: 지남 · 할 일 · 시간 정함 · 끝냄 네 카드는 **비어도 그 자리에 그대로**(제목 + "없음" 한 줄). 데스크톱 두 열 배치(왼쪽 지남 → 할 일, 오른쪽 시간 정함 → 끝냄)도 내용과 무관하게 고정 — 위치를 외워서 눈이 바로 가게. 폰은 위에서부터 같은 순서. 끝냄 카드가 접히는 것은 그대로. 빈 카드는 개수를 적지 않는다("없음" 과 겹친다). 끝냄이 비면 접기 단추 없이 "없음"
