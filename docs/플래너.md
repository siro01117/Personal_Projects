# 플래너 — 설계서 v1

> 2026-10-01. EZ.WORK 세 번째 모듈. 일정과 같이 만든다.
> 원칙은 보고서 서랍·일정과 같다. 규칙은 한 곳(`lib`·DB), 미니멀 1차, 에이전트는 MCP 로.

## 0. 정해진 것

- 플래너 = **시간이 안 정해진 할 일**. 시간이 정해지면 일정으로 간다
- 주로 **개인 할 일**을 쓴다. 일하면서 생기는 할 일은 나중에 프로젝트 모듈에서, 약속은 모임 모듈에서 넘어온다
- 그래서 일정에 직접 넣는 일은 드물다. 일정은 **플래너·프로젝트·모임·바깥 일정이 모이는 곳**이다
- 1차에 없는 것: 우선순위, 반복 할 일, 하위 할 일, 태그·목록 나누기. 없어서 막힐 때 더한다
- 누르면 보기만, 고치기는 '수정' 을 한 번 더 (일정과 같은 규칙). 단 **끝냄 체크는 바로** 된다

레퍼런스: **Things 3**(조용한 목록, 끝낸 것은 접힘), **Sunsama·Akiflow**(할 일을 캘린더로 끌어 시간 붙이기).

## 1. 흐름

```
프로젝트 ─┐                    ┌─ 모임
          ▼                    ▼
       플래너(시간 없음) ──시간 정하기──▶ 일정(시간 있음) ◀── 바깥 일정(sync)
```

- 할 일 하나에 일정은 **최대 하나**. 시간을 정하면 일정이 생기고 할 일과 이어진다
- 이어진 일정을 지우면 할 일은 다시 '시간 없음' 으로 돌아온다
- 할 일을 끝내도 일정은 남는다(그 시간에 했다는 기록). 일정 블록에 끝냄 표시
- 할 일을 지우면 이어진 일정은 남고 연결만 끊긴다

## 2. 데이터

### `ez_tasks`

| 열 | 뜻 |
|---|---|
| `id`, `owner` | |
| `title` | 1~200자 |
| `note` | 0~2000자 |
| `due` | 마감 날짜. 없어도 됨 |
| `est_min` | 걸릴 시간(분) 5~600. 시간을 정할 때 일정 길이 기본값. 없으면 60 |
| `sort` | 손으로 정한 순서 (실수, 사이에 끼우기 쉽게) |
| `done_at` | 끝낸 시각. null 이면 안 끝남 |
| `origin_kind`, `origin_id` | 어디서 넘어왔나. `project` / `meet` / null. 둘 다 있거나 둘 다 없거나 |
| `version` | 고칠 때마다 +1 |
| `deleted_at` | 지운 것. 되돌리기(5초) 뒤 지운 채로 둔다 |
| `created_at`, `updated_at` | |

### 일정 쪽에 더하는 것 (`ez_events`)

| 열 | 뜻 |
|---|---|
| `task_id` | 이 일정이 된 할 일. 살아 있는 일정 중 같은 `task_id` 는 하나만 (부분 유일 인덱스). 할 일이 지워져도 일정은 남는다 |
| `origin_kind`, `origin_id` | 프로젝트·모임에서 넘어온 일정의 구멍. 지금은 아무도 안 쓴다 |

## 3. 화면

**플래너 페이지** `/planner`
- 맨 위 한 줄 입력: 쓰고 Enter 면 맨 위에 추가. 한글 조합 중 Enter 무시
- 목록 셋, 위에서 아래로
  1. **할 일** — 시간 없음 · 안 끝남. 손으로 끌어 순서 바꾸기(데스크톱)
  2. **시간 정함** — 이어진 일정이 있는 것. 날짜·시각 순. 오른쪽에 "10/3 금 14:00"
  3. **끝냄** — 최근 14일만, 접혀 있음. 펼치면 보임
- 줄 하나: 동그라미(끝냄 체크) · 제목 · 마감("10/5 까지", 지나면 빨강) · 걸릴 시간("1시간")
- 줄 누르기 → 보기(데스크톱 오른쪽 패널, 폰 보기 시트): 제목 · 마감 · 걸릴 시간 · 메모 · 이어진 일정 · [시간 정하기] [수정] [없애기]
- **시간 정하기** → 날짜 · 시작 시각(기본: 그날 첫 빈 시간) · 길이(기본 `est_min`). 저장하면 일정이 생긴다
- 끝냄 체크는 누르면 바로. 알림에 '되돌리기'

**일정 페이지에서**
- 데스크톱 오른쪽 패널: 아무 블록도 안 고른 때는 **할 일(시간 없음) 목록**. 끌어서 격자에 놓으면 그 자리(15분 단위)에 일정이 생긴다
- 할 일에서 온 일정 블록: 제목 앞에 작은 동그라미. 상세에 '할 일에서 옴' + 끝냄 체크
- 폰: 할 일에서 시간 정하기는 플래너 쪽에서만

## 4. MCP 도구 (2개)

| 도구 | 하는 일 |
|---|---|
| `todo_list(status?, query?)` | `open`(기본: 안 끝남) / `done` / `all`. 각 줄에 이어진 일정(날짜·시각)까지 |
| `todo_save(id?, base_version?, title?, note?, due?, est_min?, done?, delete?)` | 넣기·고치기·끝냄·지우기. 고칠 땐 `base_version` 필수 |

시간 붙이기는 따로 도구를 두지 않고 `schedule_save(task_id=…)` 로 한다. 보고서 6 · 일정 4 · 플래너 2 = 12개.

## 5. 라칸 할 일 12개

- 백업 파일에서 옮긴다: 제목 · 메모 · 마감 · `duration` → `est_min` · 끝냄(`doneAt`)
- `priority` 는 버린다(1차에 없음). `slot`(시간이 정해진 것)은 오늘 이후면 일정으로 만들어 잇고, 지난 것은 버린다
- `placeId` 는 이어진 일정의 지점으로

## 6. 시험

| 층 | 무엇 |
|---|---|
| DB | RLS · 길이 제약 · origin 둘 다/둘 다 없음 · 한 할 일에 살아 있는 일정 하나 · 할 일 지워도 일정 남음 · 버전 |
| MCP | 2개 도구 입력 검사 · 오류 문구 · 낡은 버전 충돌 · `schedule_save(task_id)` 로 잇기 |
| 웹 | 추가 · 끝냄 · 되돌리기 · 순서 바꾸기 · 시간 정하기 · 일정 지우면 돌아옴, 폰 폭 포함 |
