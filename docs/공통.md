# 공통 화면 규칙 (2026-10-04)

모듈마다 따로 정하지 않고 사이트 전체에 적용하는 두 가지. 모듈 설계서보다 우선한다.

## 1. 내용은 가운데에

> "섹션들을 전체적으로 중앙으로 보낼 필요가 있음. 너무 다 왼쪽 정렬인 게 불편해, 사이트 전반적으로."

- 모듈의 **내용 기둥**(목록 · 카드 · 폼 · 표)은 최대 폭을 두고 **작업면 가운데**에 둔다(`margin: 0 auto`). 사이드바를 뺀 나머지 폭에서 가운데
- **조작 줄**(정렬 · 역할 칩 · 검색 · 단추 줄)은 그 내용 기둥과 **같은 폭 · 같은 왼쪽 선**에 맞춘다 — 조작은 왼쪽 정렬이지만 기둥 자체가 가운데라, 넓은 화면에서 왼쪽 끝에 붙지 않는다. 위쪽 바(홈 · 빵부스러기 · 밝기 전환)는 지금처럼 작업면 폭을 다 쓴다
- 기둥 최대 폭: 플래너 두 열 1,200 · 한 열 760 / 작업대 목록 760 · 집중 960 / 모임 목록 1,040 · 모임 하나 1,040 / 보고서 1,032 + 레일(이미 가운데) / 서랍 탐색기 1,200 / 일정 설정 720 / 관리(회원) 960 / 홈 1,100. 주간 시간표(`/schedule`)는 폭을 다 쓰는 격자라 그대로
- 폰(작업면 760 미만)은 지금처럼 가득 — 바뀌지 않는다
- 데스크톱 두 열이던 것은 그대로 두 열, 기둥만 가운데

## 2. 우클릭 메뉴는 어디서나

> "우클릭 메뉴도 다 있으면 좋겠고."

- 줄 · 카드 · 블록처럼 **누를 수 있는 항목**에는 **우클릭(터치는 길게 누르기) 메뉴**가 있다. 탐색기의 메뉴(`app/_ui/Menu.tsx`, 길게 누르기 포함)와 같은 모양 · 같은 동작
- 메뉴 항목은 **그 화면에 이미 있는 동작만** 모은다(새 기능을 메뉴에만 넣지 않는다). 첫 항목은 "열기/보기", 지우기는 맨 아래, 그 위에 구분선. 아이콘은 `Icon.tsx` 에 있는 것만
- 어디에 무엇을
  - 플래너 할 일 줄: 보기 · 끝냄(또는 되살리기) · 작업대에 · 수정 · 시간 정하기(또는 다시 정하기 · 시간 없음으로) · 일정으로 보내기 · 지우기
  - 작업대 목록 카드: 집중 화면 · 끝냄 · 내리기
  - 집중 화면의 단계 줄: 체크 · 떼어내기 · 지우기(단계)
  - 모임 목록 줄: 열기 · 수정 · 다음 모임 · 링크 복사(켜져 있을 때) · 지우기
  - 모임 화면의 사람 줄: 온다 · 못 온다 · 비우기(정해진 뒤) · 핀 지우기 · 빼기
  - 일정 블록(주간 · 하루): 보기 · 수정 · 이번만 바꾸기(반복이면) · 지우기(반복이면 이번만 / 전부)
  - 보고서 블록(고치기 모드): 댓글 · 위로 · 아래로 · 지우기. 읽기 모드: 댓글 · Markdown 으로 복사(그 블록만)
  - 보고서 서랍 탐색기: 지금 그대로
  - 관리(회원) 표 줄: 이름 고치기 · 비밀번호 다시 정하기 · 켬/끔 · 지우기
- 메뉴를 연 항목은 메뉴가 떠 있는 동안 선택 표시(탐색기와 같다). Esc · 바깥 누르기 · 스크롤로 닫힘. 키보드: 메뉴 키(`ContextMenu` · Shift+F10)도 연다
- 폰 길게 누르기: 500ms, 그 사이 손가락이 10px 넘게 움직이면 취소(탐색기 규칙). 길게 누른 뒤 손을 떼도 열기(탭)가 같이 일어나지 않는다
