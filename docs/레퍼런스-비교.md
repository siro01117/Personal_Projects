# 모듈별 대표 레퍼런스 · 보고서 서랍 기능 비교

> 2026-09-30. 레퍼런스는 **따라 할 대상이 아니라 "사용자가 이미 몸에 익힌 기대치"** 로 쓴다.
> 판정 기준: 없으면 **매일 쓰는 데 막히는가** (미니멀 1차).

## 1. 모듈별 대표 레퍼런스

| 모듈 | 대표 레퍼런스 | 무엇을 기준으로 삼나 |
|---|---|---|
| 홈 (런처) | 스마트폰 홈 화면 | 아이콘 + 알림 배지, 누르면 바로 들어감 |
| 보고서 서랍 — 정리 | **Windows 파일 탐색기** (조작) · Google Drive 웹 (웹에서의 기대치) | 선택·열기·끌어 옮기기·휴지통·찾기 |
| 보고서 서랍 — 읽기 | **ChatGPT 딥 리서치 보고서 화면** | 인용 번호 ↔ 출처, 내보내기 |
| 보고서 서랍 — 공유 | **Notion '웹에 게시'** | 켜기/끄기, 링크, 공개 중 표시 |
| 보고서 서랍 — MCP | **Notion 공식 MCP** | 찾기·읽기·만들기·고치기·옮기기, 결과에 링크 |
| 스케쥴러 | Google Calendar 주간 보기 | 시간 격자, 끌어서 옮기기 |
| 플래너 | Things 3 | 시간 없는 할 일 — 오늘 / 언젠가 |
| 프로젝트 관리 | Trello 보드 | 카드로 한눈에 |
| 프로젝트 디자인 도구 | Notion 킥오프 템플릿(내용) + Typeform(한 문항씩 채우기) | 질문지 → 할 일 |
| 웬투밋 + 모임 | When2meet(시간 격자) + Luma(모임 페이지·참석) | 게스트는 로그인 없이 |
| IA 작성기 | Octopus.do | 트리 편집, 도구 적게 |
| 유저플로우 작성기 | Whimsical 플로차트 | 도구 적게, 연결이 쉬움 |
| 학습기 | Anki(반복) + NotebookLM(자료 → 카드 자동 생성) | 입력은 AI 가 |
| 학습 노트 | Notion(글) + GoodNotes(펜) | 보류 중 |

## 2. 보고서 서랍 — 만든 것 vs 레퍼런스

표기: ✅ 있음 · 🔴 빠짐, 꼭 필요 · ⚪ 빠짐, 나중 · 🟡 들어갔는데 과할 수 있음

### 정리 (Windows 탐색기 · Google Drive)

| 기능 | 레퍼런스 | 우리 | 판정 |
|---|---|---|---|
| 큰 아이콘 보기 · 선택 · 두 번 눌러 열기 | 둘 다 | ✅ | |
| 위쪽 경로 · 뒤로가기 | 둘 다 | ✅ (URL 이 곧 위치) | |
| 새 폴더 · 이름 바꾸기(F2) · 겹치면 (2) | 둘 다 | ✅ | |
| 우클릭 메뉴 · 끌어 옮기기 · 옮기기 메뉴 | 둘 다 | ✅ | |
| 삭제 → 되돌리기 알림 | Drive | ✅ | |
| **찾기** | 둘 다 (맨 위 검색창) | ❌ — DB·MCP 에는 있는데 **화면에 없음** | 🔴 쌓이면 못 찾는다 |
| **휴지통 보기·복원** | 둘 다 | ❌ — 알림이 사라지면 복원할 길이 없음 | 🔴 실수 한 번이 영구 손실처럼 보임 |
| **새로 들어온 것 찾기** | Drive '최근 문서', 탐색기 '즐겨찾기/최근' | 보고서에만 점. **폴더 안에 새 보고서가 있어도 폴더엔 표시 없음** | 🔴 에이전트가 깊은 폴더에 넣으면 못 찾는다 — 이 제품의 핵심 흐름 |
| 여러 개 선택(Ctrl/Shift) | 둘 다 | ❌ | 🔴 기본기 — 한 번에 옮기기·복사·삭제 |
| 목록 보기(날짜·종류 열) | 둘 다 | ❌ | ⚪ |
| 정렬 바꾸기 | 둘 다 | ❌ (폴더 먼저 이름순 고정) | 🔴 기본기 — 이름순/날짜순 |
| 복사·잘라내기·붙여넣기·복제 | 둘 다 | ❌ | 🔴 기본기 — 손이 먼저 간다 (처음엔 '필요 없음'으로 잘못 봤음) |
| 실행취소 Ctrl+Z | 둘 다 | 알림의 되돌리기만 | 🔴 기본기 |
| 깊이 8단 제한 | 없음 | ✅ | 안전장치. 드러나지 않으니 유지 |

## 3. 정리

**꼭 넣을 것 7개** (작은 순)

1. MCP 결과에 웹 링크 — 아주 작음
2. 인용 번호 → 출처로 이동 + 올리면 미리보기 — 작음
3. 공개 중 표시(탐색기 아이콘에 작은 표시) — 작음
4. 폴더에 안 읽음 표시 전파(안에 새 보고서가 있으면 폴더에도 점) — 작음
5. 찾기 화면(위쪽 줄 검색. DB `ez_search` 준비됨) — 작음~중간
6. Markdown 으로 복사 — 중간
7. 휴지통 보기·복원(묶음 단위) — 중간

**과할 수 있는 것**
- 차례 레일: 블록이 많을 때만(예: 8개 이상) 보이게
- 홈 점선 타일 8개: 결정 필요 — ① 그대로 ② 만든 모듈만 보이기 ③ 모듈이 하나뿐인 동안은 홈 없이 서랍으로 바로
