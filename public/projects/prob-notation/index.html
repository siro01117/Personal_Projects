직접 정의 답안 첫 줄에 "…라 하자"로 정의하면 쓸 수 있다
문제 읽을 때 순서
  1. Ω부터 적는다무엇을 몇 개 뽑는지, 순서가 있는지. n(Ω)가 곧 분모다.
  2. 사건을 문자로 정의한다"A = …"를 안 적고 시작하면 절반은 다른 사건을 세고 있다.
  3. 조건을 기호로 바꾼다적어도 하나는 ∃, 모두는 ∀, 독립이면 ⊥, 이미 일어났다면 P(·|B).
  4. ∃가 보이면 뒤집는다P(∃) = 1 − P(∀¬). 대부분 여사건이 훨씬 작다.
  5. 답안은 말로 다시 쓴다메모용 기호는 "전체 경우의 수는", "여사건의 확률이므로"로 번역한다.
문제

불량품 3개가 섞인 제품 10개 중 4개를 임의로 꺼낼 때, 적어도 하나가 불량품일 확률을 구하시오.

메모 메모용
  • Ω = 10개 중 4개, n(Ω) = ₁₀C₄ = 210
  • B = 불량 집합, n(B) = 3, n(Bᶜ) = 7
  • 구할 것: P(∃불량)적어도 하나 → 뒤집기
  • = 1 − P(∀정상) = 1 − n(Bᶜ 중 4개)/n(Ω)
  • = 1 − ₇C₄/₁₀C₄ = 1 − 35/210 = 5/6
답안 교과 안

10개 중 4개를 꺼내는 전체 경우의 수는 ₁₀C₄ = 210이다.

불량품이 하나도 없는 사건을 A라 하면, A는 정상품 7개 중 4개를 꺼내는 경우이므로 n(A) = ₇C₄ = 35이다.

구하는 확률은 A의 여사건의 확률이므로 P(Aᶜ) = 1 − 35/210 = 5/6.

규칙표는 한 장으로

몇 달 같은 기호만 써야 압축 효과가 생긴다. 기호가 바뀌면 다시 말로 번역하는 시간이 들어서 이득이 사라진다.

기호 등급은 2015 개정 교육과정 수학(하) 집합·명제 단원과 확률과 통계 교과서 표기 기준. 채점 기준은 학교마다 다를 수 있다.
